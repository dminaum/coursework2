# 📄 Вакансии с HeadHunter API

Проект для поиска, фильтрации и вывода вакансий с использованием API HeadHunter.  
Позволяет искать вакансии по запросу, фильтровать их по ключевым словам и зарплате, выводить топ-N лучших предложений и сохранять результаты в JSON-файлы.

---

## 🚀 Как работает программа

Пользователь взаимодействует через консоль:

1. Вводит поисковый запрос (например, `Python разработчик`).
2. Вводит количество топ-вакансий для вывода (например, `10`).
3. Вводит ключевые слова для фильтрации (например, `Django Flask`).
4. Указывает диапазон зарплаты (например, `100000 - 200000`).

Далее происходит:

- Загрузка вакансий с HeadHunter API.
- Перевод их в объекты `Vacancy`.
- Фильтрация по ключевым словам и зарплате.
- Выбор топ-N вакансий по уровню зарплаты.
- Сохранение результата в `data/result_vacancies.json`.
- Вывод вакансий в человекочитаемом формате в консоль.

## 📚 Описание основных компонентов
### Vacancy
Класс описывает вакансию с полями:
- name — название вакансии
- salary_from, salary_to — диапазон зарплаты
- url — ссылка на вакансию
- requirement — требования к кандидату
Также реализовано:
- Валидация данных
- Сравнение вакансий по зарплате (<, ==)
- Преобразование в словарь (to_dict)

### helpers.py
Содержит утилиты:
- Удаление HTML-тегов
- Преобразование вакансий из API в объекты
- Фильтрация по ключевым словам и зарплате
- Сортировка вакансий по зарплате

### hh_api.py
Класс для работы с HeadHunter API:
- Получение списка вакансий по поисковому запросу
- Сохранение полученных данных через JSONSaver

### json_saver.py
Класс для работы с файлами:
- Сохраняет данные вакансий в формат JSON.

### 📌 Пример работы
Запустите программу и следуйте инструкциям.
Ввод:
```bash
Введите поисковый запрос: Python разработчик
Введите количество вакансий для вывода в топ N: 2
Введите ключевые слова для фильтрации вакансий: Django Flask
Введите диапазон зарплат (например, 100000 - 200000): 120000 - 200000
```
Вывод:
```bash
Название: Python Backend Developer
Зарплата: 150000 - 180000
Требования: Опыт работы с Django и Flask
Ссылка: https://hh.ru/vacancy/123456
----------------------------------------
Название: Junior Python Developer
Зарплата: 120000
Требования: Знания Python, Django
Ссылка: https://hh.ru/vacancy/789101
----------------------------------------
```
Результаты будут сохранены в файл data/result_vacancies.json.
